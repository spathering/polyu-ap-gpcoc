## 已确认情况

安装和启动 exe 已编译，8 项真实进程自动测试通过；从独立 Python 环境启动服务、执行 Lua 行动、停止和恢复均已有证据。当前 Windows 窗口自动化工具初始化时报告 kernel assets 路径缺失（os error 3），重置后仍无法初始化，因此未完成窗口视觉和鼠标交互核对。

这是一项验收缺口，目前没有已确认的窗口功能缺陷，不把自动化环境问题等同产品故障。

## 后续步骤与验收

1. 在 Windows 桌面双击安装 exe，检查中文、日志和取消/关闭行为。
2. 使用新的隔离存档目录启动，人工检查首次密码两次输入、取消和成功建立房间。
3. 检查自动打开页面、窗口“打开页面”“查看日志”“停止”按钮与关闭窗口后释放端口。
4. 在常用 DPI 缩放下确认无文本遮挡，记录系统版本、截图和发现的问题。

避免使用正式存档做首次初始化实验。完成后将结果写入桌面工具验证说明，有真实缺陷则另行记录复现与修复；通过后按维护标准归档本问题。
