# Lasers & Feelings 轻量跑团资料与前端方案

本案例选用 John Harper 的 **Lasers & Feelings v1.4**，中文暂译《激光与情感》。它是由主持人与玩家共同推进故事的轻量科幻角色扮演游戏，作者页面标注 3—6 人、约 2—4 小时，规则书只有一页。人数与时长来自作者介绍，不是本工程的会话限制。

2026-10-30：按需求重新选择实际的跑团规则，删除此前不适用的连通棋资料。本目录保存完整官方规则书、可检索正文、中文规则整理、配置包准备分析和前端方案；**尚未实现规则包或正式前端**。

| [前端方案](frontend-design.md) | 角色、共同建船、协助检定、特殊洞察和主持工作台 |

选择理由：单一角色数值和六面骰让规则编写负担较小，同时保留玩家叙事、主持裁定、多人协助、秘密信息与自由问答，能够检验通用跑团工具的关键需求。地图、网格战斗、计时驱动和背包重量并非本案例的必要条件。

后续顺序：先确认[待讨论取舍](frontend-design.md#7-待确认与实施顺序)，再复核后端最新接口、实施规则包与前端、进行多人验收。本轮只完成资料与设计。
