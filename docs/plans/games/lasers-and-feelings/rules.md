## 1. 适用范围

依据 John Harper 的 Lasers & Feelings v1.4 一页规则书，以下为覆盖全部游戏环节的中文整理。完整英文原文见[本地 PDF](sources/lasers-and-feelings-original.pdf)；译名仅供本工程讨论。原书没有完整预写剧情，提供冒险生成表与主持方法；本稿不把额外创作的剧情伪称原书内容。

玩家是星际侦察船 Raptor 的船员，探索未知宇域、接触友善或危险的外星人，保护 Consortium 的世界。Darcy 船长受到神秘精神实体 Something Else 的影响，正在医疗舱恢复，船员必须自行处理危机。主持人（GM，在工程中对应 KP）描述局势、提出问题并裁定后果，玩家决定角色如何行动。

## 2. 创建角色

| 步骤 | 全部原书选项或要求 |
| --- | --- |
| 风格 | Alien 外星人、Android 仿生人、Dangerous 危险、Heroic 英雄气概、Hot-Shot 王牌、Intrepid 无畏、Savvy 精明 |
| 职责 | Doctor 医生、Envoy 使者、Engineer 工程师、Explorer 探险家、Pilot 飞行员、Scientist 科学家、Soldier 士兵 |
| 角色数值 | 选择 2、3、4、5 中的一个整数；数值越高越擅长 LASERS，越低越擅长 FEELINGS |
| 姓名 | 取一个适合太空冒险的名字，原书举例 Sparks McGee |
| 个人目标 | 当上船长、认识新外星人、射击坏人、发现新世界、解开奇异太空谜团、证明自己、继续保持出色，也可以自创 |

LASERS 指技术、科学、冷静理性与精准行动；FEELINGS 指直觉、外交、诱惑，以及热情冲动的行动。玩家目标是积极卷入冒险，并尽力应对。

每位角色起始拥有：内置太空行走服的制服；兼具电话、摄像、通信、扫描和通用翻译功能的装置；通常设置为击晕模式的可变光束相位手枪。原书没有给它们定义重量、射程格数、伤害骰或数值加成，不应自行填入并称为原规则。

## 3. 共同创建飞船

Raptor 从下列七项中共同选择**两项优势**：高速、灵活、武装精良、强力护盾、优越传感器、隐形装置、舰载战斗机。

再从下列四项中选择**一个问题**：

| 问题 | 叙事含义 |
| --- | --- |
| 耗能大户 | 总是需要能量水晶 |
| 仅一个医疗舱 | 而且 Darcy 船长正在使用 |
| 糟糕的断路器 | 战斗中舰桥控制台容易爆炸 |
| 恶劣名声 | Darcy 船长过去做过坏事 |

这些特征提供叙事依据，不自动产生规则书未规定的固定加骰。

## 4. 冒险检定与协助

只有行动存在风险或结果不确定时才掷骰。基础为 1d6，充分准备加 1d，属于专长加 1d；主持人根据角色与局势确定骰数。额外协助见下文，因此不能把总骰数永远写死为最多三颗。

逐颗比较点数与角色数值：

| 比较情况 | 结果 |
| --- | --- |
| 使用 LASERS，点数小于角色数值 | 该骰成功 |
| 使用 FEELINGS，点数大于角色数值 | 该骰成功 |
| 任一模式，点数恰好等于角色数值 | 该骰也成功，并触发 LASER FEELINGS（特殊洞察） |
| 其他 | 该骰不成功 |

汇总成功骰数，原书列出的后果为：

| 成功数 | 叙事结果 |
| --- | --- |
| 0 | 事情出错；主持人说明局势如何恶化 |
| 1 | 勉强达成；主持人加入复杂情况、伤害或代价 |
| 2 | 良好完成 |
| 3 | 关键成功；主持人赋予额外效果 |

**特殊洞察**：玩家可以向主持人提问，主持人必须如实回答。原书问题示例覆盖：对方真实感受、幕后主使、如何让对方做某事、应该警惕什么、实现目标的最佳途径、事情的真相。原书没有“相等就失败”、洞察后重掷或自动改变检定模式的规定。

**协助**：先说明如何帮助，再作一次自己的检定；成功则给被协助者 **+1d**，并不是直接给主检定增加一次成功。协助本身的具体情境仍由主持人裁定。

原书没有细定多人协助上限、递归协助、超过三次成功的归类、多颗相等骰带来的提问次数或提问处理时机。这些事项应在开团时约定，不宣称存在唯一官方答案。候选工程约定见[包准备方案](package-preparation.md#5-需要确认的本地裁定)。

## 5. 主持人生成冒险

四栏各掷一次 d6 或直接选择，组合为“某威胁想对某对象做某事，并将导致某种结果”。下表保留全部 24 个选项。

| d6 | 威胁 | 想要 | 对象 | 将导致 |
| --- | --- | --- | --- | --- |
| 1 | 征服者 Zorgon | 摧毁／腐化 | 太空海盗之王／女王 | 毁灭一个恒星系 |
| 2 | 蜂群舰队 | 偷窃／捕获 | 虚空水晶 | 逆转时间 |
| 3 | 叛变船长 | 与其结合 | 恒星无畏舰 | 奴役一个星球 |
| 4 | 太空海盗 | 保护／强化 | 量子隧道 | 发动战争／入侵 |
| 5 | 赛博僵尸 | 建造／合成 | 远古太空遗迹 | 撕开现实裂隙 |
| 6 | 外星脑虫 | 平息／占领 | 外星神器 | 修复一切 |

## 6. 主持方法

通过游玩发现船员如何击败威胁，而不是预先写好结局。先展示威胁最近造成的恶果；在威胁伤及角色前给出征兆，然后询问玩家如何应对。例如敌舰正在给巨炮充能，接下来由玩家行动。

结果不确定时才要求掷骰，不预定检定结论；失败也要推动事件发展，每次掷骰后局势都应发生变化。向玩家提问，并将答案纳入故事，例如询问谁曾遇见虚空教徒、在哪里、发生过什么。

原书没有强制回合、数值生命值、升级表、网格地图或背包容量系统。伤害、资源消耗与场景位置可以由叙事表达；如以后加入数值追踪，应作为独立扩展。
