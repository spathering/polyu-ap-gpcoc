## 1. 目标与实施状态

首版已按 R0—R6 实施于 `tools/room-manager/`，与 `engineering/` 分离，拥有独立 EXE、构建、配置及测试入口，通过 HTTP/WS 访问宿主。[当前实现](../current/engineering/room-manager.md)与[验收报告](../../tools/room-manager/docs/acceptance.md)记录实际交付；本计划保留后续 H/S 工作包。

第一阶段交付“现有接口管理 + 连接期间变化观察 + 创建备份”。第二阶段另行设计和实施权威变更历史及完整存档管理。首版不以修改宿主为前提；发现真实接口缺口先登记 Issue，按设计缩小操作范围或另行安排宿主任务，不能将文件直写作为替代。

## 2. 依赖与里程碑

顺序：R0 契约/运行探针 → R1 独立骨架与会话 → R2 查询工作区 → R3 管理写入；R2 完成后可进行 R4 观察与关注；R3/R4 → R5 集成/GUI 验收 → R6 发布与文档。

| 工作包 | 依赖 | 施工内容 | 交付物与退出条件 |
| --- | --- | --- | --- |
| R0 运行与契约基线 | 无 | 验证 C# WinForms/.NET Framework 4.8 x64、HTTP/WS/Cookie/CSRF、中文与 DPI；对照宿主 capabilities/contracts 和管理操作；确认源码目录无占用 | 独立探针、依赖与协议基线、测试用宿主数据目录；能登录 KP 并接收完整分片快照。不通过则修改选型/计划，不以未验证方案推进 |
| R1 独立工程与连接 | R0 | 创建工具目录、可复现构建、会话状态机、后台任务/取消、回环地址校验、认证、重连、错误处理、本地设置 | 单独 exe 可运行；不引用 engineering 中的 DLL/Python/venv，不启动宿主；退出只关闭工具连接；KP 降权和迟到响应清理通过 |
| R2 读取与展示 | R1 | 概览、配置/规则修订、实例/关系/进度、成员/素材/流程；view 与 admin 各自时间戳、搜索筛选、只读 JSON、加载/空/超限/失败状态 | 数据与实际接口一致；未知字段不丢失；不显示不存在的全量分页和归档对象浏览功能；播放器账号无法读取管理数据 |
| R3 修改与回执 | R2 | 按设计接口表接入配置/实体/关系/进度/成员/房间/流程/素材操作；完整规则组暂存激活；备份创建；编辑草稿、冲突、回执查询与结果未知处理 | 所有首版列出的操作均有成功/拒绝提示及刷新；实体带编辑基线 token；非原子操作明确边界；无后台盲重发 |
| R4 观察与关注 | R2 | WS 分片基线、admin 单任务轮询、字段差异、观察段/缺口、独立审计页、关注定义、记录/任务队列限额 | 首样本不制造变化；中间态合并与断线缺口表述正确；不按时间猜测操作者；对象不可见和真正删除不混淆 |
| R5 集成与界面验收 | R3、R4 | 自动边界测试、隔离真实宿主及两个管理会话、至少一个真实桌面窗口人工/自动操作、性能与错误体验检查 | 第 3 节所有首版验收项通过，证据、版本、限制齐全；GUI 验收失败不能只用接口测试替代 |
| R6 独立发布与文档 | R5 | 可复制发布目录、版本/源码摘要、独立依赖说明、使用文档、操作说明与索引同步、清除失效说明 | 在 engineering 之外的新路径启动发布 exe 验证；宿主运行不依赖工具；文档与实际操作一致，施工登记释放 |

R0—R6 已施工。R3 使用按操作字段生成的表单与局部结构字段输入，不提供任意整对象写回；未知字段只读。R5 的本机通过范围和未覆盖设备条件以验收报告为准，不能把下面的验收目标表自动当作全部环境已验证。

## 3. 首版验收矩阵

| 场景 | 预期与证据 |
| --- | --- |
| 独立性 | 宿主使用自己的入口先启动；把发布目录复制到不含工程源码的位置，exe 能连接；关闭工具后房间继续运行 |
| 连接与认证 | 正确/错误密码、缺 CSRF、错误 Origin、服务未启动、会话过期、玩家登录、连接重定向均有明确结果；Cookie/令牌不进入日志 |
| 状态一致性 | 多分片乱序/重复/缺失/超限不产生半份视图；仅合法完整快照更新界面；多次断线后无重复轮询/重连任务 |
| 配置 | 创建配置、提交新修订、引用阻止删除；修改配置默认值不改变既有实例；提交前检测到外部变更时不静默覆盖 |
| 规则工件 | 导入完整 Lua/JSON 组、暂存失败保持旧版、显式激活/回退；无文件保存即自动激活；旧流程锁版行为仍由宿主保证 |
| 实例与关系 | 创建/改名/数值/标签/归属/可见性/规则入口编辑、关系新增与移除、非法引用拒绝、归档被引用对象拒绝；未支持字段只读 |
| 编辑竞争 | 两会话编辑同一实体：先提交者成功，旧 token 提交者收到冲突，草稿保留供比较；不能自动改用新 token 重发 |
| 非 CAS 操作 | 配置、关系、进度等显示实际保护级别；前置刷新不宣传为原子保护；多命令操作部分成功时逐条显示回执 |
| 成员与进度 | 修改成员和设置进度成功/拒绝均与宿主一致；最后 KP 保护；角色变更后清理不再授权的管理缓存 |
| 流程 | 查看等待、布尔回应、取消与 retry；重复回答/已到期拒绝；retry 明示为新尝试，不能当断线重发 |
| 素材 | 授权上传/下载、引用挂接和被引用禁止移除；不会直接访问宿主资产目录；上传结果未知不自动重复 |
| 命令结果未知 | 主机已提交但丢响应后，查询或原封套重发只执行一次；拒绝换新 commandId 盲重试；重启 GUI 后可查询保存的最小命令记录 |
| 备份创建 | 成功显示宿主 backupId 和不含身份库说明；超时显示结果未知；没有下载、列表、恢复能力时不伪装为已完成这些动作 |
| 观察差异 | 单字段变化、缺字段/null、数组变化、嵌套路径、对象新增/不再可见均正确；排除传输 token 噪声 |
| 观察缺口 | 快速 10→5→8 或 10→5→10 只展示实际收到的样本；重连开新段，明确无法补齐缺失过程；不伪造源修改时间 |
| 审计来源 | 宿主最近 100 条审计与本地观察分开；不显示不存在的字段前后值或无证据的操作者关联 |
| 关注与缓存 | 对象/字段关注、禁用、删除、重启加载定义；账号/房间/权限变化不泄漏前值；不以 demo ID 合并不同连接 |
| 容量与响应 | 以设计默认 2000 条观察/100 项关注和接近宿主 2 MiB 的合法快照测试；记录实际耗时/内存；UI 可操作、取消有效、队列有界，超限明确提示 |
| GUI 实际操作 | 中文、长字段、键盘焦点、滚动、不同 DPI、禁用状态、冲突对比、错误提示和确认对话框均从真实窗口验证并保留截图/步骤 |

集成数据全部使用隔离目录，禁止对真实游玩存档做删除、撤权、归档或故障注入。时间/网络故障用受控测试端注入；涉及重试语义必须至少一次对真实宿主验证，不能只用 mock。

测试依据分层：差异/命令状态机单元测试；HTTP/WS 协议测试；真实宿主集成；真实桌面交互。未改宿主时运行相关兼容检查即可，不为 GUI 布局改动反复跑全部游戏包回归。若调整宿主，另按影响范围执行原有测试。

## 4. 文档、目录与发布要求

施工前登记唯一 ID、路径和时间，重新读取确认；代码路径只在实际创建后进入 hierarchy。R0—R6 的常用占用范围是 tools/room-manager/ 及本轮需要更新的文档；真实宿主测试要登记测试输出路径，宿主代码仅登记使用。任何接口修改前须另行扩大改动范围并检查冲突。

施工期的有效设计正文维护在本设计与本计划，不复制第二份方案。实现后 tools/room-manager/docs/ 维护工具操作与开发说明，docs/current/engineering/ 提供实际接口对接及发布状态的入口；计划只有全部完成或被替代才归档，有剩余验收则保留并逐项记录状态。

发布清单至少包括：工具版本、宿主协议版本/契约基线、框架要求、exe 摘要、构建方式、运行说明、测试结果与已知限制。发布内容不得包含测试账号凭据、连接 Cookie、观察到的房间值或宿主备份。工具更新不修改现有安装/启动 exe 的配置，不自动升级宿主。

## 5. 后续工作包（不在首版施工内）

| 工作包 | 前置设计 | 验收重点 |
| --- | --- | --- |
| H1 权威变更记录 | 宿主事务记录模型、顺序号/权限过滤、前后值范围、命令关联、保存期限、游标缺口；明确已有数据不具备完整追溯 | 每次已提交变更可查询，事务失败不产生成功记录；同命令重试不重复；隐藏数据不泄漏 |
| H2 变更历史接入 | 授权分页/按对象过滤、订阅与补查契约；工具从“观察”切换或并列显示“权威历史” | 断线补齐、过期游标提示、重复事件去重；不将早期本地样本标为权威 |
| S1 备份管理接口 | 列表/元信息、完整性校验、受控导出/删除、权限与保留策略 | 备份状态与实际文件一致；不能删除运行存档；失败或不完整备份不可恢复 |
| S2 恢复生命周期与 GUI | 停止写入与活动流程处理、身份绑定、恢复目标、宿主生命周期入口、失败回退、会话失效 | 实测恢复成功/失败/中断、原存档保护、重新连接及观察基线重建；不能只验证按钮请求成功 |

H 与 S 可分别规划，但涉及同一宿主事务或文件生命周期的改动按占用和依赖协调。完整变更历史可能增加存储量，需先评估文件代与配额；该评估不自动触发数据库迁移。
