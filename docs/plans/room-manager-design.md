# 房间管理器后续设计

- 文档类型：计划
- 状态：进行中
- 创建日期：2026-11-05
- 最后更新：2026-11-09
- 关联文档：[当前 Python 实现](../current/engineering/room-manager.md)、[LAN 设计](../current/engineering/network-lan.md)、[施工计划](room-manager-construction-plan.md)、[原设计背景](../history/2026-11-09-room-manager-design.md)

管理器首版已实现，2026-11-09 按用户要求迁移到 Python 并增加独立 LAN 网关和 GUI。现行技术和接口边界的唯一正文在上述工程文档；旧 WinForms 设计已归档。

待设计的能力包括：

1. H1/H2 权威变更历史：宿主事务内顺序号、对象字段前后值、命令与操作者关联、权限过滤、保留期限、分页游标和断线补查。不能倒推本地样本为完整历史。
2. S1/S2 完整存档管理：备份列表、校验、受控导出和删除；恢复需要停写、活动流程处理、身份绑定、失败回退及会话失效。不能由 GUI 直接修改存储绕过接口。
3. LAN 扩展：跨设备/防火墙验收、可选 TLS、自动发现、配置包页面接入。公网、P2P 与穿透另行规划，不通过放宽 Host/Origin 校验实现。
4. 管理协作：统一非实体 CAS、长期压力与跨设备 DPI、更多界面可用性改进。

这些均为后续事项，未包含在当前已实现能力中。后续技术取舍需结合具体使用需求讨论。
