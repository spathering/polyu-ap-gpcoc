# 检定—裁定—后果：A0 阶段简化稿

这是纸面流程稿，不是可执行的流程定义。原参考为 `docs/plans/project planning/lua-script-reference/05-check-with-ruling.lua`，可恢复阶段属于 A2，尚未实现。

```text
业务输入：角色、技能、预先声明的伤害
├─ 阶段 check：调用检定，保存 passed
│  ├─ 成功：结束
│  └─ 失败：进入 ruling
├─ 阶段 ruling：等待 KP 对既定后果回应
│  ├─ 拒绝：结束
│  └─ 同意：进入 apply
└─ 阶段 apply：调用伤害，然后结束
```

阶段名是稳定逻辑标识，不依赖行号。作者不填写状态结果路径、每个字段的输入映射或效果表；宿主未来通过模板和具名结果绑定补齐。每个运算阶段独立提交，等待单独持久化；KP 批准不能授予新权限。A2 必须验证崩溃恢复、重复回应和等待后数据变化，不能用当前同步宿主模拟通过来代替。
