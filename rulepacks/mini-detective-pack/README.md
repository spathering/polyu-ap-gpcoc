# 铃蔓回转录：规则复原与配置草案

本包根据 `raw/` 中五张企划图片和《铃蔓回转录》工作簿整理，新增 `raw/UI/` 三张截图作为前端参考。`mini-detective-pack` 是工作目录名；目前只能确认工作簿使用“铃蔓回转录”这个名称，不能据此认定正式作品名、作者或版本。

当前交付为 **0.2.0 自动行动与分区界面实现**：KP 顶部“自动处理”开关控制后续行动：开启时常规行动、标准谜题和卡片处理自动结算，关闭时提交主持裁定；普通结果只更新 KP 日志；特殊方法和语义分歧进入独立裁定队列。场景页集中显示可前往地点、当前行动和现场机关／物品，小地图为页内折叠窗，仅显示该PL已探索房间及其一跳可见周边。KP 顶部“下一轮”可主动推进。已有13条Lua规则、五账号原生入口与桌面单标签前端；验证范围见[验收](tests/README.md)。规则与场景仍基于复原草案，不表示官方原作。原始材料保持原样。

新增独立[配置包服务管理.exe](配置包服务管理.exe)，可在不登录 KP 的情况下启动、停止和重启本包服务。关闭管理窗口不停止后台，需点击“停止服务”。

直接双击对应入口：[KP主持人.exe](KP主持人.exe)、[PL1观察员.exe](PL1观察员.exe)、[PL2护卫.exe](PL2护卫.exe)、[PL3文献员.exe](PL3文献员.exe)、[PL4医护员.exe](PL4医护员.exe)。未启动时自动启动隐藏服务，已启动则复用；没有固定默认密码；新设备首次在网页设置密码并自动准备规则、世界时钟、四个预设及初始道具，后续各入口仍须用对应账号登录。已有角色不重置。Git 不同步账号与运行存档。新设备登录失败的处理见[原生入口说明](tools/README.md#新设备登录与-auth_failed)。

原[start.ps1](start.ps1)方式仍可用，默认本机8888端口。数据仅在本包runtime目录，工程代码与原存档未改动。详细步骤见[实现与运行](docs/implementation.md)。
