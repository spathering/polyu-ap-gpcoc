占位使用口径：

- 道具使用类别图标＋真实中文名称／份数／星级。长枪、刀、铁棍等允许暂用泛化武器／工具图标，不从图形推导属性；枪图是步枪剪影，仍以本包“展示枪”文案为准。
- 所有地点已有类别绑定，室内统一建筑图标，村落用房屋类图标，森林用树，海岸用船。岛屿图标只是总览装饰，不代替地图拓扑，未揭露地点也不能因已配素材而显示。
- 人物先用hood剪影配角色名，不代表角色一定戴兜帽；不预设真实人物肖像、性别、年龄或原作立绘。
- 旧纸纹理用于卡片边缘或档案装饰；原图有较深底与破损边，不平铺在正文背后，也不当作宽屏照片拉伸。正文仍使用计划规定的纯色底。
- 首次接入先用本地文件，运行时不依赖外站图片热链；图片失败回退文字与类别框，仍能建卡、调查、制卡和裁定。卡片图片完全可选。
