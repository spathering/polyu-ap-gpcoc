## 1. 目标、范围与版本

以已有企划机制为主，补足一套能由主持人手工执行的调查、生存和战斗规则。版本 `reconstruction-0.1`。R／I／H分别表示原料、推测、补充，编号见证据文档。涉及配置的全部缺省值均以本版为单位采用，不能视为原作者确认。

官号／企组在本文统一称主持人；玩家各操纵一名角色。固定事件面向全体；探索与遭遇以参与者私密渠道处理（R1）。玩家通过行动选择、调查、交涉与信息交换推进故事；战斗不是唯一解法（H）。原作人数没有可靠统一值；厨房48份食物与角色表53人是不同场景记录。本版建议1名主持、2—4名玩家，提供4张预设卡（H）。

## 2. 建卡与基本判定

### 六维与才能

六维是体质、力量、速度、侦察、精神、智力。初始均为1—5整数，总和20（R4）；不是在六项基础1之外再分20。每人选一项窄专长“才能”，另记名称与适用范围，适用时以5作检定值（R4数值5，适用方式H）。才能不得替代战斗力量、速度、HP、资源上限或一切调查；例如“机械维修”可检修留声机，不能自动洞悉所有谜题。需在投骰前由主持确认。

| 属性 | 用途 | 来源 |
| --- | --- | --- |
| 体质 | 决定HP和体力档位，不参与常规五类行动判定 | R2／R4，HP公式I |
| 力量 | 破坏、搬运、战斗对抗 | R3／R4 |
| 速度 | 先攻、闪避、到达顺序 | R3／R4／R6 |
| 侦察 | 搜索隐蔽细节、追踪迹象 | R4，具体用途H |
| 精神 | 抵抗异常、保持自控 | R4，具体用途H |
| 智力 | 分析、推理，并提供每日提问／追加行动额度 | R4／R6，额度定义H |

HP上限=`3×初始体质`，初始满血（I）。体质1—3：初始体力2、上限3；体质4—5：初始体力3、上限4；后期有效体质6沿用第二档（R2）。临时体质改变不自动治疗；永久变化由主持显式调整HP上限并将现HP裁剪至新上限（H）。初始携带物选一件合理日常用品，经主持确认，武器最高2星（H）。

### 普通检定

掷1d6（I），`骰点≤有效属性`成功（本版采用R4示例）；失败不代表角色不知道玩家已掌握的事实。属性3时1、2、3成功，4、5、6失败。本版无通用“大成功／大失败”；原料特定的锤砸玻璃允许力量骰出1破坏，作为场景特例保留（R6事件栏I8）。常规属性临时修正后裁剪至1—6；基础建卡约束不变（H）。

成功率随有效属性1—6依次为1/6、2/6、3/6、4/6、5/6、6/6。掷骰前明确属性、风险和结果；同一方法失败后须改变条件才可重试（H）。

主动对抗若场景未写专式，双方各掷1d6，比较“有效属性−骰点”，较大者胜；平手维持现状（H）。战斗使用§6专式。没有风险或没有有意义失败后果的行动直接完成（H）。

## 3. 三种时间与两种资源

### 现实报备

原料要求每日21点前报备次日计划，次日12点开放小窗（R1），原文没有时区。本版异步模式用Asia/Shanghai，21:00收计划、次日12:00开始处理；现场试跑可关闭现实报备，不改变游戏内时间（H）。错过报备默认安全地点休息，不能自动替玩家选择攻击、交出重要物或加入阵营。

### 游戏日与行动轮

每日8轮：上午1、上午2、下午1、下午2、晚上1、晚上2、凌晨1、凌晨2（R2）。每轮每个角色只能选择一个主要行动：探索、移动、睡眠、治疗、交涉或固定事件等（H）。探索中的最多2次侦察是该主要行动内部的尝试，不再推进全局轮次；战斗一攻一守的“交锋”也不是每日行动轮。

角色提交整日计划，主持逐轮按先后结算。计划发生新遭遇、通路阻断或重伤时，可暂停并让玩家修改尚未结算轮次；已确定结果不可倒改（H）。缺席角色留在当前安全处休息。

### 体力与智力额度

| 行动 | 时间 | 体力 | 智力额度 | 处理 |
| --- | --- | ---: | ---: | --- |
| 探索一处 | 1轮 | 1 | 0 | 含抵达相邻地点与每人最多2次侦察 |
| 单纯移动一条邻接边 | 1轮 | 0 | 0 | 不含搜索；危险地点仍可能遭遇 |
| 睡眠 | 1轮 | 0 | 0 | 体质1—3恢复1，4—6恢复2，不超过体力上限 |
| 提问／剧情推理反馈 | 不占额外轮 | 0 | 1 | 每日额度初值=智力，超额不答权威提示 |
| 额外侦察一次 | 当前探索内 | 0 | 1 | 支付后再掷，仍受物品和队伍上限约束 |
| 额外主要行动 | 占后续最近一个空闲轮 | 按行动 | 1 | 允许修改原本“休息”的后续轮；一天仍最多8轮 |
| 一场遭遇战 | 占触发的当前轮 | 1 | 0 | 一场只扣一次；逃跑另扣1 |
| 治疗／制作／安抚 | 1轮 | 0 | 0 | 另需道具、才能或场景允许 |
| 固定事件 | 预定轮 | 0 | 0 | 覆盖该轮计划，不重复扣探索费 |

体力消耗用途和睡眠恢复来自R2；逐项费用、同轮战斗额外费用、智力独立额度和额外行动定义均为H。智力额度每日开始刷新，不消耗智力属性；不得以“额外行动”无限延长一天。

体力为0仍探索等，先抽一次疲劳状态，本次行动照常处理，体力保持0；每次强行付费行动只抽一次（R2允许强行及睡眠清除，抽取频率H）。体力只有1而探索后触发战斗时，战斗的1点用同一强行规则处理。**逃跑例外**：当前体力不足1时禁止，不能强行逃跑（R3）。睡眠恢复体力并清除疲劳，不自动回HP；每天不自动回满体力或HP（H）。

## 4. 探索、组队与信息

报备至少包含日期／轮次、参与者、出发地、目的地、方法、想寻找的东西和优先级，参考R2。主持先确认可到达、人数、成本及风险，再给环境描述和要求判定，最后私发反馈。

单队1—4人；每人每次地点访问含2次侦察，额外每次扣1智力额度；一队同地点最多获取3件道具（R6线索总结A8）。本版把“同地点”限定为该队同一游戏日对该地点的累计，拆队／重进不刷新（H）；核心信息不计入3件实体道具，实体钥匙仍计数。每名角色同地点的2次基础侦察也按日累计，换队不刷新（H）。

同轮不同队伍去同一地点，比较队中最慢速度；最快队先到，平速掷1d6较大者先，仍平重掷（R6原文只规定掷骰，大小方向H）。后队相对首队在`1+速度差`个局部调查动作后到达（R6）；这里的局部动作是一次小队搜索尝试，不是游戏轮。每次由队伍指定一个角色执行并占其次数。在双方行动耗尽前尚未达到延迟时，后队在该轮末抵达；不能因此在同一地点额外占用数天或剥夺其整个行动（H）。到达即允许谈话、冲突或资源竞争；地点不是最多容纳4人的空间，4人是协作队伍上限。

原料“大部分道具由玩家意愿产出”（R2），本版解释为允许玩家提出合理搜寻对象，由主持检查库存或生成普通物；不能因此要求必出枪械、正确答案或无限补给（H）。新增物需有唯一实例、星级、效果和库存来源。

调查分层（H，参考W1—W3）：到场且采取合理调查，就获得推进所必需的核心信息；侦察骰决定额外证据、可拿的装备或代价。失败仍给最低线头，可以附带惊动、受伤或耗时。推理是否正确由证据与主持真相决定，智力骰不能代替玩家推理或改变已定谜底。

## 5. 线索卡、道具卡与资源

官号文字反馈不能直接转发给他人，但可以自己绘制线索卡公开；线索卡可以造假，主持不保证其叙述真实（R4）。用户于2026-11-02确认：当前线索卡和道具卡均可暂用纯文字替代手绘，图片／手绘为可选附件（H，已接受的交互形式）。文字卡不豁免原始回执保密、真实道具实例和KP审核规则。系统应保存“主持原始证据”和“玩家发布卡”两套记录，私密原文不随公开卡泄漏。

道具获得官号文案后须制作道具卡才能使用，不可伪造，每人手持道具卡上限4（R4）。本版将4解释为携带的实体卡槽总数，装备武器也占1；背包、箱子不能绕过槽位，线索卡不占槽（H）。同卡耗材最多3份，超过则另占槽；套装须按物品目录定义，不允许把所有武器塞为一个“工具箱”。

获得第5张前，必须选择不领取、交给同地同意接收者、放入共享储物处或丢弃；不得静默删除旧物。转移需双方同地和接收确认，同轮可作附带操作；使用后数量扣减，0则销毁；公用唯一物原子领取，只能有一个持有人（H）。未制卡物品为“待确认”，不提供数值或剧情效果。

产出上限按实体数量计，耗材一份计一件，不按合并后的卡片张数计（H）；例如取3份口粮即用完该队当天该地点的3件额度。领取先确定归属并占槽、占产出，再审核道具卡面；退回卡面不重新扣次数或发第二实例（H）。满包领取允许处理本次相关的转交、寄存或丢弃，不因事件进行中禁用必要整理。

武器1—5星分别对应小型日用品、中小型器具、大型器具、专门冷兵器、热兵器（R6特殊文案A6:A10）。基础伤害加值=星级（I，R5武器2／3与R3公式）；无武器为0（H）。单次攻击只使用1件武器。弹药、药包与特殊效果见场景配置，不能以星级推出额外射程、连射或区域伤害。后期记录中的7星不进入初始通用表。

## 6. 遭遇战

### 一次交锋

1. 确认双方位置、参战人、已制卡武器与状态，按§3支付参战体力。多人战拆成明确的攻击序列，不做未定义的同时互击（H）。
2. 速度高者先攻，平速骰较大者先，平手重掷（R3／R5；骰大小方向H）。先攻只决定第一次，之后每次交锋交换攻守。
3. 守方先选对抗或闪避，再公开攻击骰，防止看完结果后择优（H）。攻方分别掷力量骰、速度骰，各1d6。
4. 对抗时守方只掷力量骰；闪避时只掷速度骰（R3／R5）。
5. 依下面公式扣HP、结算状态；HP归零即停止该角色的攻击。若双方仍能战斗则交换攻守（R3，归零处理H）。

记攻击者有效力量为Sₐ、速度Vₐ、武器Wₐ；守者为Sᵈ、Vᵈ、Wᵈ；相应骰点为dSₐ、dVₐ、dSᵈ、dVᵈ。

- **对抗**：`差值=(Sₐ−dSₐ+Wₐ)−(Sᵈ−dSᵈ+Wᵈ)`。差值<0扣1HP；差值≥0扣差值HP（R3字面）。守方成功压制也会受到最低1伤害，但刚好持平伤害为0；这是原文的非单调现象，先保留，不擅自改为最低1。
- **闪避**：若`Vᵈ−dVᵈ > Vₐ−dVₐ`，成功，伤害0；相等也算闪避失败。失败伤害=`max(0,Sₐ−dSₐ+Vₐ−dVₐ+Wₐ)`（R3；非负裁剪H）。

本版战斗的属性差值不先裁剪为0，也不先做普通“骰点≤属性”的成功筛选。攻击力量骰失败也可能因武器造成伤害，不能混合两套机制。

### 逃跑、结束与多人补充

在自己的攻击机会可改为逃跑，扣1体力，秘密选一个相邻且可通行区域；追击者选一个相邻区域，同地点则立刻再遭遇，否则脱离（R3）。本版追击不另耗体力或主要轮，但每个逃跑机会只猜一次，下一次逃跑仍需支付1点；禁止枚举所有邻区（H）。被追上属同一场战斗，不重复扣参战费；新遭遇重新比较先攻。

HP=0为倒地、不能行动／防御／逃跑，未获同意不自动永久死亡；治疗到正值可在下一轮恢复行动（H）。战斗可因倒地、逃离、投降或双方停战结束。玩家不主动接受PVP时不强制进入玩家互杀路线，交涉和救援可替代。

战后`当前HP×2<HP上限`者抽一次伤势状态（R3）；恰好一半不抽。同一场只抽一次，不因主持分段重复抽。多人试跑按速度从高到低依次各做一次攻击，目标逐次选防守方式；全员走完称一整回合，下一回合顺序保持。人数不对称不能一打多时简单交换两个人的身份（H）。

## 7. 状态、治疗与异常

原料提供六段异常叙事，但没有可执行效果和触发条件。本版不直接把精神异常描写当强制行为指令。采用下面可撤销、可记录的状态（全部效果H）：

| 1d6 | 疲劳状态（强行行动） | 伤势状态（战后低于半血） |
| --- | --- | --- |
| 1 | 乏力：力量检定−1 | 擦伤：下一次普通力量检定−1 |
| 2 | 迟缓：速度检定−1 | 跛行：下一次普通速度检定−1 |
| 3 | 眼花：侦察检定−1 | 疼痛：下一次普通侦察检定−1 |
| 4 | 分神：智力检定−1 | 惊惧：下一次普通精神检定−1 |
| 5 | 不安：精神检定−1 | 失衡：下一次战斗先攻速度−1 |
| 6 | 困倦：下一次普通检定−1 | 挫伤：下次移动须同伴协助或多用1轮 |

同类不叠加强度，新抽到已持有类型刷新；不同类型可并存。疲劳只作用普通检定、先攻与队速，不参与战斗伤害和闪避公式（H，避免累积把属性压垮）；困倦优先于其他疲劳，下次普通检定总疲劳修正最多−1。睡眠清疲劳，伤势用一次后消失或治疗清除。体力0连续行动仍可能积累多个不同疲劳。

精神检定失败获得“惊扰”：下次普通检定−1后清除，不可叠加，睡眠或音乐／浴场安抚可清除（H）。原料只有“回san”文字，没有SAN点数，本版不设置独立SAN条。污染、寄生、人外、魔法只作为可选扩展关闭；若启用必须逐项定义成本、持续、抵抗、冷却和解除，不从后期表格零散文字自动生成能力。

医疗包使用一次，耗1轮、恢复3HP并清1个伤势；有医学才能不额外掷骰，无才能过智力，失败恢复1HP且同样消耗（H）。睡眠不回血，进食不直接回复体力，基础2日试跑不额外引入饥饿扣血；食物短缺先作为剧情压力。主动叙事安抚或治疗不得强迫他人接受身体变化。

## 8. 主持执行顺序与样例

每轮：锁定计划→固定事件覆盖→按队速安排到达→校验和支付资源→描述环境→玩家选择方法→判定／私发核心信息→结算道具归属和状态→更新位置及已用次数→记录结果→进入下一轮。原料未明确的结算细节均为H。

- 普通检定：侦察3掷3成功；掷4失败，仍给当前场景的核心线头。
- 对抗：攻力量4骰2武器2，守力量3骰4武器1，差值`4−0=4`，扣4；差值−2扣1；差值0扣0。
- 闪避：复原R5，B速度5骰6得−1，A速度4骰4得0，A闪避成功。若守得−1则平手失败。
- 战后：HP上限9，剩4触发，剩5不触发；上限12剩6不触发。
- 疲劳：体质2、体力0强行探索，抽迟缓；睡眠一轮回复到1并清疲劳，不恢复HP。
- 组队：快队最低速度4，慢队最低速度3，快队先做2个局部动作，慢队到达；两队仍各自受道具库存和每日上限约束。

## 9. 待确认、实施与验收

优先确认：骰面与≤、才能的5含义、对抗0／负数伤害、战斗体力收费、智力额度、HP公式、同地点上限的刷新周期。场景谜题与结局是独立补写，也需另行接受。

步骤：先按本版四人卡人工走完一轮探索和一场战斗，再走完场景到任一结局，记录资源是否阻塞调查；有新证据时按来源逐条修订。验收须覆盖建卡20点、属性边界、0体力与逃跑、第五卡、核心线索失败保底、对抗与闪避平手、多队到达、午夜唯一物和断线不重扣。当前只做文档与算例检查，尚未证明游戏平衡或工程支持。
