原料为用户提供的文件，不等同于已确认官方出版物。图片已逐张目读，工作簿以 OOXML 只读提取，保留工作表名与单元格坐标；未改写或重算原文件。全书七张表未发现公式，数值多为手记，不存在可用来直接恢复规则的自动计算模型。角色与每日行动表中的后续状态不宜回填初始配置。

- **原料 R**：可以直接在提供材料定位的描述。它可能是草稿或会话记录，不保证内部一致。
- **推测 I**：由多个样本归纳的规律，仍待原作者确认。
- **补充 H**：为让流程闭合而新定的规则、参数或剧情。网络启发仍归 H。

规则和场景全文的统一默认选项是试跑提案，不升级为“当前工程能力”。

## 4. 关键冲突及处理位置

| 问题 | 原料证据 | 草案处理 |
| --- | --- | --- |
| 普通检定 `<` 还是 `≤` | R4文字写小于；力量3的例子写≤3成功，又仅写大于4失败 | 采用≤；4也失败。保留不一致记录，详见规则 §2 |
| 骰子面数 | R5攻击和闪避示例有1、4、6点；R6另有20面水晶骰子道具 | 普通判定暂用1d6（I）；水晶骰子不是全局检定骰的证据 |
| 体质上限 | R4建卡最高5，R2体力分档写4—6 | 建卡最高5；6只作为后期效果可配置值，禁止初始自由分配到6 |
| 才能如何影响数值 | R4说一项才能力5；R6天赋多是自由文本 | 另设一个窄专长的检定值5（H），不免费把某个六维改成5 |
| HP与精神资源 | 无独立HP生成条款；R6样本支持3倍体质；事件栏写“回san”却无SAN上下限 | HP采用3倍（I）；不凭“回san”引入COC百分骰或SAN点数 |
| 伤害下限 | R3仅写负数扣1，未写0 | 对抗差值0扣0，负数扣1，保留原文异常曲线供试跑检验 |
| 闪避示例比较符号 | R5称 `[5−6]=−1 < [4−4]=0` 且A成功 | 按角色归属重写：守0>攻−1，所以成功；不照抄符号方向 |
| 行动点／体力／行动轮 | 图片和表格交替使用名称 | 行动点归为体力同义词；一天8轮是时间，不是额外8点资源（H） |
| 智力消耗 | R6线索总结A8未说明扣属性还是次数 | 单设每日智力额度，消耗不改变智力属性（H） |
| 原作剧情完整度 | 国际象棋、星空、餐盘等缺题面，日记缺姓名地址，地图缺邻接 | 场景给出可运行替代内容，全标H，不称恢复原谜底 |
