树桩镇原版插画归原权利人所有。原预览保存在研究目录，发布配置包时需按已确认许可处理。新图稿采用自行生成的鼠类、树桩和纸卡视觉，实际生成时以观察到的风格特征编写提示词，未将原版预览作为编辑目标。苔绿和锈红为本包增加的操作色。

本轮通过内置 image_gen 生成界面设计图，并对建角提示、庭院私密物品、检定算式和场次资料状态进行了定向修订。完整提示词见[生成记录](../ui-design/prompts.json)。
