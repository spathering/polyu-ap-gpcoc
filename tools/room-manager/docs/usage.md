## 启动与连接

运行 `dist/RoomManager/RoomManager.exe`，或双击工具目录的 `start.cmd`。复制部署时必须复制整个 `RoomManager` 文件夹，包括 `_internal/`，无需另装 Python 或 .NET。管理器仍位于 engineering 之外，不启动房间宿主、不打开存档文件。

先使用宿主自己的入口启动房间，在“房间管理”页输入真实宿主地址或 LAN 网关地址、KP 账号和密码。接受回环及 RFC1918 私有 IPv4 地址，首版使用 HTTP，限可信局域网。玩家账号不能进入管理界面；玩家可用浏览器访问 LAN 地址的通用操作台。

配置包网页端口不一定是宿主端口。例如 mini-detective-pack 的网页代理只转发 HTTP，不能转发 WebSocket。若登录后持续等待快照，应填写宿主进程 `serve --port` 对应地址，或本次新增 LAN 网关的共享地址。端口不固定时，以当前启动信息为准。

## 管理操作

左侧选择对象类别、搜索和换页；右侧显示原始 JSON，并提供按操作字段生成的表单。每页最多显示 500 项，这是已接收数据的本地分段。可选字段只有勾选后才提交；数值表、数组、规则绑定等使用多行 JSON 编辑框，普通名称使用字符串，枚举和布尔值有独立控件。

| 对象 | 可用操作 |
| --- | --- |
| 配置 | configuration.put/remove；更新内容使用新修订，默认数值不会自动迁移实例 |
| 角色及其他实例 | entity.create/patch/update/archive；支持名称、数值、标签、归属、可见性和规则绑定；归档受引用约束 |
| 关系与进度 | relation.set/remove、progress.set；没有关系原地修改和进度删除 |
| 成员与房间 | member.update、room.status；不能停用最后一个 KP，不提供本机账号创建/密码管理 |
| 规则 | 导入完整 Lua/JSON 文件组，提交 rule.stage；查看工件后用 rule.activate 显式激活或回退 |
| 流程 | 等待查看、flow.respond/cancel/retry；retry 是新尝试，可能重新掷骰 |
| 素材 | 上传、下载、asset.attach/remove；上传限制 10 MiB，可选公共或仅 KP |
| 备份 | 请求宿主创建备份，显示 backupId；不含身份库，无备份列表、下载、删除和恢复 |

例如修改 HP：选中 entities 中的角色，选择 entity.update，勾选 numbers，输入 `{"hp":8}`。数值表按宿主接口合并；标签填写 `["melee"]`。owner 填 `null` 可清除归属。规则绑定例如 `{"attack":{"ruleId":"规则ID"}}`，宿主负责最终校验。

实体提交保留开始编辑时的 viewToken；冲突后草稿保留，可用“比较最新值”对照，再“重建编辑基线”并重新填写。其他写入在提交前对选中对象重读比较，但没有原子版本保护。不要将前置比较理解为全面防止并发覆盖。

规则导入选择完整的 Lua/JSON 文件组；同名文件拒绝，暂存不自动激活。工件列表选中修订后可查看源码和相对当前版本的变化，激活旧修订可回退；既有流程的锁版由宿主保证。

## 观察、关注与回执

“观察到的变化”分别比较 WS 和 admin 样本，第一份只作基线。记录包含观察 ID、观察段、来源、接收时间、转义路径及前后值；缺字段与 null 分开，消失标为“不再可见”。数组整体比较，不把 viewToken 或运行指标当作业务变化。宿主最近审计单列展示，不凭时间猜测操作者。

选中对象后填写 `/numbers/hp` 等字段路径，或留空关注整个对象。关注可禁用、删除，并可仅显示关注命中的变化。默认最多 100 项关注、2000 条内存观察，观察另有 16 MiB 估算 JSON 限额；达到限额淘汰最旧记录。WS 与轮询可能合并中间状态，断线后清空旧观察段，不补造历史。

命令结果未知时，先查询回执或原封套重发；界面阻止生成新 commandId 盲目重做。原封套仅留在当前内存中；重启后只能用保存的最小命令记录查询。上传和备份没有命令回执，超时可能已经执行，不能自动重复。

设置保存在 `%LOCALAPPDATA%/OnlineCOC/RoomManager/python-settings.json`，只保存关注和最多 200 项命令查询元信息。首次运行时若只有旧 `settings.json`，读取其中的关注与查询记录并转换地址/路径；原文件不改动。不同实例可用 `--settings-dir <目录>` 隔离设置，避免后写者覆盖。密码、Cookie、完整命令和观察值不落盘。

## 局域网面板

切换“局域网联机”：填写真实本机宿主地址、当前机器的明确 LAN IPv4 和共享端口，确认使用可信局域网后点击启动。不能绑定 0.0.0.0 或公网 IP；127.0.0.1 仅供本机测试。网卡候选来自本机地址，操作者需选择实际使用的网卡。

将共享地址发送给同一局域网成员；玩家用浏览器打开通用操作台，以原宿主账号登录。另一个 Python 管理器可用同一共享地址以 KP 登录。面板可查看连接数/HTTP 请求数、复制地址和停止网关。若远端打不开，检查网卡、网络隔离与 Windows 防火墙所选端口；工具不自动修改防火墙。

关闭管理器会停止由它启动的网关，宿主继续运行。需要独立窗口时使用 `RoomManager.exe --lan`。后台独立运行方式见[LAN 模块说明](../../../engineering/network-lan/README.md)。当前只转发通用宿主接口和操作台，不转发游戏配置包自己的网页、自动化或启动器服务。
